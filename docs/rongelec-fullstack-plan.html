DeepSeek 海事英语翻译工作流

中文页签可保存、生成英文初稿或创建空白英文版。英文始终是独立草稿，必须由管理员修改、确认后才影响 /en 页面。

1. 冻结中文快照保存当前中文版本，翻译期间后续中文编辑不会影响本次结果。
2. 创建 PG 任务同一内容和版本只允许一个排队/处理中任务，避免重复点击。
3. Worker 领取短事务 SKIP LOCKED；领取后立即提交，不在事务中等待 AI。
4. 保护富文本按段落提取文字，行内格式用占位符保留；图片、表格、链接、字号不交给 AI。
5. 匹配术语后台术语库只注入命中的最多 50 条海事术语。
6. DeepSeek 初稿V4-Flash 输出国际海事英语、英式拼写的 JSON。
7. 校验与写回检查路径、占位符、术语和分块数量，生成英文草稿。
8. 人工发布英文页签调整并确认；失败可重试，已发布英文不会被覆盖。

英文状态

未创建、AI 初稿、手动编辑、已确认、中文已更新待复核；后台显示英文落后中文的版本数。

任务可靠性

单块只重试一次；429、500、503 或空响应可重试。处理中超过 10 分钟自动标记失败。

术语库 CRUD

中文术语、固定英文、备注、启用状态和版本号。翻译记录提示词、模型、术语版本和 token 用量。

公开展示：中文发布 V2 而英文待复核时，英文访客继续看到最后一个确认版本 V1。英文从未发布时，语言切换显示不可用按钮，英文 URL 返回 404。

内容模型与发布流程

1. 草稿填写基础信息与稳定 slug
2. 中文快照保存可追溯的中文富文本版本
3. 英文草稿AI 初稿或从空白手动编辑
4. 媒体与 SEO选择封面、相册、替代文本和双语 SEO
5. 确认发布首次双语确认；后续语言独立更新并刷新缓存

任意合理屏幕尺寸的连续自适应

流动容器

clamp() 控制字号、间距和留白；最大内容宽度限制阅读行长。

自动网格

auto-fit + minmax() 让卡片按可用空间自然从多列变单列。

文本安全

按钮自动换行；英文长词可断行；标题平衡换行；正文保留可读字号。

媒体安全

图片、视频最大宽度 100%；表格只在自身区域滚动，页面本身不横向滚动。

不按设备型号做三套页面，断点只在内容无法容纳时触发。自动验证 320–2560px 的连续宽度抽样、横竖屏、英文文本膨胀和 200% 缩放；页面不使用整页缩放。

图片与有声首页视频

首屏视频

  • 原始有声母版保存在 OSS
  • 桌面 1080p、手机 720p，均保留 AAC 音轨
  • 先显示 ≤150KB 封面，再延迟加载视频
  • 默认静音自动播放，点击按钮开启声音
  • 省流量、慢网或减少动态效果时仅显示封面

图片

  • OSS 原图 + CDN 响应式尺寸
  • AVIF/WebP，JPEG/PNG 回退
  • 首屏优先，其余懒加载
  • 保存宽高，避免页面跳动
  • 案例列表只加载缩略图
CDN 必做：MP4 正确 Content-Type、版本化对象键、HTTPS、长期缓存、Range 回源，并通过 206 Partial Content 验证。

联系表单接口 → QQ 邮箱

浏览器表单姓名、公司、联系方式、船舶/故障描述
后端接口接收数据、字段校验、蜜罐、IP 限流
连接 QQ 邮箱通过 QQ SSL SMTP 接口投递邮件
QQ 收件箱指定 QQ 邮箱收到联系方式

只实现“联系表单 API → QQ 邮箱”的投递接口，不建设独立发信域名，也不在数据库保存留言正文。发送失败时提示重试，并展示 hmm@rongelec.com 与公开电话作为备用联系方式。

安全、上线与运维

服务器基线

  • 公网只开放 80/443
  • SSH 限制管理来源，数据库不暴露
  • 非 root 部署与密钥登录
  • Compose restart、healthcheck、日志轮转
  • CPU、内存、磁盘、证书和容器告警

应用基线

  • 密码强哈希、安全 Cookie、CSRF 与登录限流
  • 富文本服务端安全过滤和 AST 路径校验
  • DeepSeek 仅由 Worker 调用，密钥只放服务器
  • OSS 短期签名与文件校验
  • 后台与预览页面禁止搜索引擎收录

公网 Git 密钥保护

  • .gitignore 屏蔽 .env、密钥文件、备份和本地部署配置
  • .env.example 只有变量名和假占位符
  • QQ 授权码、百度网盘 API、OSS、数据库和会话密钥只放服务器
  • 首次公网推送前扫描已跟踪文件和完整 Git 历史
  • 推送前与 CI 持续扫描，命中即阻止
  • 泄露后先撤销轮换，再清理 Git 历史

禁止进入仓库

真实 QQ 邮箱或管理员私人账号、授权码、API Key/Secret、AccessKey、密码、私钥、带凭据的连接串、生产数据库备份，以及日志中打印出的配置值。

上线顺序：数据库备份 → 向后兼容迁移 → 启动新镜像 → 健康检查 → 页面/登录/发布/邮件/Range 烟雾测试 → 切换流量。失败则回切旧镜像；涉及数据结构时按迁移说明恢复。

测试与验收标准

功能

双语页面、案例 CRUD、英文 AI 草稿与人工确认、发布与下架、QQ 邮件和管理员认证。

翻译可靠性

冻结快照、段落 AST 回填、术语命中、重复任务、超时回收、失败重试和英文历史版本回退。

容量

用 100 条测试数据验证分页和查询，不提供批量导入入口。

响应式

320–2560px、横竖屏、英文文本膨胀和 200% 缩放，无页面级横向溢出。

性能

移动端 LCP ≤2.5s、CLS ≤0.1、INP ≤200ms；手机不请求桌面视频。

恢复

数据库备份可恢复；旧站可回切；缓存发布与 CDN 版本更新可验证。

Git 安全

用测试密钥验证提交和 CI 扫描能够拦截；前端代码、构建产物与日志均不含服务端凭据。
